# Trick or Treat! 🎃

A Halloween English adventure for Grade 4 by **Oops! English!**

Five houses, twenty challenges, collectible awards and background music.

## Play

Enable GitHub Pages in Settings → Pages, deploy from branch `main`, folder `/ (root)`.

Open `index.html` through a local web server for local play. Progress and music preferences are saved in your browser.

All game artwork and audio are included.
